# TPI JavaScript et Manipulation DOM

## 📋 Description
Premier TP de HTML/Javascript 
Application interactive démontrant la manipulation du DOM via JavaScript.

## 🚀 Fonctionnalités implémentées
- ✅ Système de volume avec barre interactive
- ✅ Gestion du mute avec feedback visuel  
- ✅ Validation de formulaire "Oui/Non"
- ✅ Navigation par sections avec checkboxes
- ✅ Ajout dynamique d'éléments DOM
- ✅ Renommage dynamique des labels

## 🛠️ Technologies utilisées
- **HTML** - Structure globale
- **CSS** - Styles et mise en page
- **JavaScript** - Logique interactive
- **Git/GitHub** - Versionning et collaboration
